# MVP Roadmap

## Phase 1 — Manual liquidity
1. Зібрати 30–100 перевізників на одному коридорі: Україна ↔ Польща або Україна ↔ Німеччина.
2. Додати рейси вручну або через Telegram-команди.
3. Дати перевізнику готовий пост для груп і deep link на бронювання.
4. Всі бронювання вести через бота.
5. Підтримку робити вручну.

## Phase 2 — Trust layer
1. Soft verification: телефон, Telegram, фото авто, документи.
2. Badge: Community / Verified / Professional.
3. Рейтинг після completed trip.
4. Скарги й ручна модерація.

## Phase 3 — Money layer
1. Часткова передоплата.
2. No-show protection.
3. Комісія тільки за confirmed booking.
4. Пізніше — escrow/refund rules.

## Phase 4 — Carrier SaaS
1. Кабінет перевізника.
2. Повторні клієнти.
3. Аналітика рейсів.
4. Автопублікація лише в партнерські групи, де є дозвіл.
